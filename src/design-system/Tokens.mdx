## Shared utilities

`src/styles/shared/ui.css` defines the `@utility ui-*` atoms that component modules `@apply` —
`ui-screen`, `ui-app-header`, `ui-field`, `ui-task-row`, `ui-chip`, `ui-notice`, `ui-empty` and the
rest of the repeated patterns.

Never put a class-descendant selector in a shared utility: CSS module class names are hashed, so the
descendant would silently stop matching. Element descendants and `&`-pseudo selectors are fine.
